## What worked, and must be kept

- **Measuring before deciding, when the decision was about a measurement.** AC-LEAK-01's criteria
  could not be executed — 100 000 iterations take ≈ 100 s, so a 60-second sampling cadence yields
  two points and a 24-hour slope is a ×864 multiplication. The spike ran first, Guy arbitrated on
  its output, and [ADR 0038] amended the *method* while leaving every threshold alone. The
  reframing that settled it was arithmetic nobody had done: **100 000 iterations is 34.7 days of
  production**, so the run is thirty-five times longer than the window it was accused of not
  covering.
- **Reading the clause instead of its twin.** 4.19's whole finding — [#100] — exists because
  chapter 4's `topics-nbirth-bdseq-increment` states *two* obligations where chapter 6 states one.
  Two separate instructions (the epic's own AC, and a note in the matrix) each pointed at a
  different wrong answer. Only reading the sentence produced the right one.
- **Falsification that destroys its own hypothesis.** Twice: the fetch deadline set to 1 ns
  *passed*, refuting my published diagnosis of [#94]; the interest-cache experiment captured both
  lines, refuting the replacement. Both were retracted in public before they could become
  received wisdom. **A falsification that only ever confirms is a ritual.**
- **Two verification methods that catch disjoint things.** Mechanical checking of citations found
  a test that does not exist and two stale line numbers — no reading would have. Repeated
  execution found two harnesses that blamed the code under test — no static check would have.
  Neither found the other's defects.
- **Naming what a gate does NOT cover, inside the gate.** AC-LEAK-01 says in its own header that
  the HTTP client's nominal path is unexercised; 4.16 says the 24-hour window is not covered.
  A green gate that quietly omits the likeliest failure site is worse than no gate, because it
  gets cited.

## What went wrong

- **A conformance row moved without the evidence it claimed.** 4.12 marked
  `payloads-nbirth-timestamp` `conformant` citing [#30]'s own prescription as falsified — but the
  mutation was applied one layer away from the call site the issue named. Applied literally, it
  left the *whole suite* green. Found by review, repaired the same day; the row now has the
  assertion it always claimed.
- **The same review missed a stale summary row for a day.** The whole-specification table read
  `38 · 4 · 8` for chapter 6 while chapter 6's own tally read `39 · 4 · 7` — internally consistent
  because the Total had been built from the stale row. I reviewed 4.12 that morning and did not
  see it. 4.19 found it; the checker now compares every chapter tally with its row.
- **A cited test that does not exist, committed again.** 4.11's review had already recorded *"a
  doc comment claimed an assertion that does not exist"*. 4.19 shipped
  `the_birth_then_data_sequence_is_contiguous` — nothing by that name — in a row written to close
  a completeness audit. The lesson had been written down and not turned into a check; it is now
  ([#101]).
- **A wrong diagnosis published as fact.** I read `cause: Some(SourceUnreachable)` as proof of a
  timeout without checking that the same cause covers `Transient`. A repair shipped on it, was
  reverted, and the retraction is on [#94]. The log was consistent with my hypothesis and with
  the truth; only the code distinguished them.
- **Two harnesses that accused the bridge of their own failure.** `chaos_poller_wedge` fell
  through silently when the UI never bound, then reported `THE BLOCKED LOOP NEVER READ AS WEDGED`
  with an *empty* body. The panic-probe waited for a UI that answers rather than a loop that runs.
  Both mine, both from this epic.
- **[#94] is unresolved and it now costs a push in two.** Six refusals today, one of them on a
  commit containing only Markdown. 47 targeted reproduction attempts, zero failures; only the
  gate produces it.

## Decisions this epic leaves on the table **[Guy]**

1. **[#100] — the first `bdSeq` is 1, and chapter 4 requires zero.** Recorded as a deviation, not
   repaired. The fix is not a constant: `before_first()` = 0 with `start()` advancing is exactly
   what makes the persisted path correct across restarts. Making the first session zero means
   representing "no file yet" as distinct from "the file says 0".
2. **[#94] — how much is a reliable gate worth?** The remaining work is instrumenting the gate
   itself rather than the code under test, and I have exhausted the cheap reproductions.
3. **[#101] — migrating 53 line citations to symbols.** A chore, best done in one pass, and the
   gate could then enforce it.
4. **[#102] and the leak gate's twin residue — a soak environment.** Two NFRs now say "production
   is the window". A day-long observation would close both.
5. **NFR10's thresholds.** Left at 3 s / 5 s with p95 measured at 0.1 % of budget. Tightening
   would make them a regression detector rather than an operator promise; the margin is on the
   record either way.

## Readiness assessment

**Epic 4 is closable.** All nineteen stories are settled, the conformance record closes with no
remainder, and both NFRs it carried are measured rather than argued. What it leaves open is
recorded with evidence in seven issues, none of them a defect introduced by this epic.

**The bridge's readiness is unchanged by this epic, by design** — `CONTRACT_VERSION` never moved.
What changed is how much of its behaviour is *proven* rather than believed: anti-replay is
observed on the wire through two different failure modes, a wedged poller is distinguishable from
an honest silence, and the drop counters can be seen to move.

**The one thing that should not be carried into Epic 6 unexamined is [#94].** A pre-push gate that
refuses half of what it is given trains people to reach for `--no-verify`, and `CLAUDE.md` is
explicit that using it is an on-record claim. That erosion is the risk, not the failing test.

## Key takeaways

- **A document of record is load-bearing.** ADR 0010's overstatement kept a `MUST` violation
  invisible for an epic, and its copy in another artifact was as authoritative to the next reader
  as the original. Correcting the source was not enough; the copy had to be annotated too.
- **Green is not evidence — it is the absence of one kind of evidence.** The conformance checker
  passed while the document contradicted itself, because the total had been computed from the
  stale figure. Consistency and correctness are different properties.
- **The cheapest way to write a wrong citation is to copy a stale one.** Both of this epic's false
  citations were inherited rather than invented.
- **Say what a measurement does not cover, at the place someone will read it.** Twice this epic
  the honest sentence went into the gate's own header, not only into a story file nobody opens
  twice.
